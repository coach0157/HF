# สรุปฟังก์ชันการทำงานทั้งหมด (Product Overview)

เอกสารนี้สรุปทุกฟังก์ชันที่ระบบทำได้จริงตอนนี้ (ผ่านการทดสอบแล้ว) แยกตามแพลตฟอร์มและ
บทบาทผู้ใช้ — ใช้เป็นฐานสำหรับทำเอกสารขาย/นำเสนอ/สเปกสินค้าต่อได้เลย

**สถานะรวม:** MVP + Phase 2 + ฟีเจอร์เพิ่มเติมนอกสเปก เสร็จและผ่านการทดสอบทั้งหมด
(unit test 192+ / e2e test 211+ ผ่านหมด) — Phase 3 (จองพื้นที่/ชำระเงิน/CCTV) ยังไม่ทำ

---

## 1. แพลตฟอร์มที่รองรับ

| แพลตฟอร์ม | ใช้โดย | เทคโนโลยี |
|---|---|---|
| แอปมือถือ (Android/iOS) | ลูกบ้าน + รปภ. (แอปเดียว สลับหน้าตามบทบาท) | Expo / React Native |
| เว็บ Admin Dashboard | นิติบุคคล/ผู้ดูแลระบบ | React (เปิดผ่านเบราว์เซอร์ ไม่ต้องติดตั้ง) |
| Backend API | ระบบหลังบ้านที่ทุกแพลตฟอร์มเรียกใช้ | NestJS + PostgreSQL |

รองรับ **หลายหมู่บ้านในระบบเดียว** (multi-tenant) — แต่ละหมู่บ้านข้อมูลแยกจากกัน
สนิท ไม่เห็นข้อมูลข้ามหมู่บ้าน (ตรวจสอบด้วยการทดสอบเจาะระบบโดยเฉพาะ)

---

## 2. ฟังก์ชันตามบทบาทผู้ใช้

### 2.1 ลูกบ้าน (Resident) — แอปมือถือ

| ฟังก์ชัน | รายละเอียด |
|---|---|
| เข้าสู่ระบบ | เบอร์โทร + OTP (ไม่ต้องจำรหัสผ่าน) |
| เชิญแขก / สร้าง QR | กำหนดชื่อแขก, เบอร์โทร, ทะเบียนรถ, ช่วงเวลาที่อนุญาต, ใช้ครั้งเดียว/หลายครั้ง — แชร์ QR ให้แขกได้ทันที |
| ยกเลิก QR | ยกเลิก QR ที่สร้างไว้ได้ทันทีถ้าส่งผิดคนหรือเปลี่ยนใจ |
| ประวัติเข้า-ออก | ดูรายการแขกที่เข้ามาในบ้านตัวเอง พร้อมรูปถ่ายหน้างาน (ถ้ามี), กดยืนยัน "แขกออกแล้ว" ได้เอง |
| ปุ่ม SOS ฉุกเฉิน | กดค้าง 2 วิ (กันกดพลาด) ส่งพิกัด GPS ไปยัง รปภ. ที่ปฏิบัติหน้าที่อยู่ทันที |
| ประกาศ | ดูฟีดประกาศจากนิติบุคคล แยกสี ปกติ/สำคัญ/ฉุกเฉิน พร้อมแจ้งเตือนแบบ push |
| แชท | คุยกับนิติบุคคลและ รปภ. แบบ 1:1 + ร่วมกลุ่มหมู่บ้าน แนบรูปได้ |
| แจ้งซ่อม | แจ้งปัญหาพร้อมหมวดหมู่+รูปแนบ ได้เลขที่ใบงาน ติดตามสถานะได้ |
| เรียกรถโดยสาร | ดูเบอร์วิน/แท็กซี่ที่หมู่บ้านแนะนำ กดโทรออกได้ทันที |
| โปรไฟล์ | ดูข้อมูลบ้าน, อัปโหลดรูปโปรไฟล์, ออกจากระบบ |

### 2.2 รปภ. (Guard) — แอปมือถือ

| ฟังก์ชัน | รายละเอียด |
|---|---|
| เข้าสู่ระบบ | เบอร์โทร + OTP |
| เข้า-ออกเวร | เปิด/ปิดสถานะปฏิบัติหน้าที่ (มีผลต่อการรับแจ้ง SOS) |
| สแกน QR | สแกนแล้วเห็นข้อมูลแขก/รถทันที ยืนยันเข้า/ปฏิเสธได้ |
| บันทึกด้วยมือ | กรณีไม่มี QR — ถ่ายรูปบัตร ปชช./ทะเบียนรถ + กรอกข้อมูลเอง |
| ยืนยันแขกออก | ยืนยันแขกออกจากหมู่บ้าน (แยกจากการสแกนเข้า กันกดพลาด) |
| รับแจ้งเหตุ SOS | เห็นรายการแจ้งเหตุแบบเรียลไทม์ พร้อมพิกัด/เลขบ้าน กดโทรกลับได้ทันที |
| **บันทึกตรวจรอบ** | ถ่ายรูปพร้อมวันเวลาประทับตอนเดินตรวจรอบหมู่บ้าน แนบหมายเหตุ+พิกัดได้ — เป็นหลักฐานว่าตรวจจริงตามเวลา |
| แชท | คุยกับนิติบุคคลและลูกบ้านได้ |
| โปรไฟล์ | อัปโหลดรูปโปรไฟล์, ออกจากระบบ |

### 2.3 นิติบุคคล/แอดมิน (Admin) — เว็บ Dashboard

| ฟังก์ชัน | รายละเอียด |
|---|---|
| แดชบอร์ดสรุป | ภาพรวมตัวเลขสำคัญของหมู่บ้าน |
| จัดการประกาศ | สร้าง/แก้ไข/ลบ, เลือกระดับความสำคัญ, กำหนดกลุ่มเป้าหมาย (ทั้งหมด/โซน/บ้านเฉพาะ) |
| ดู SOS | รายการแจ้งเหตุฉุกเฉินทั้งหมด พร้อมพิกัด/สถานะ |
| จัดการสมาชิก/บ้าน | เพิ่ม/ลบ/แก้ไขสมาชิกทุกบทบาท (ลูกบ้าน/รปภ./แอดมิน), ผูกบ้านเลขที่ |
| จัดการเวรยาม | เปิด/ปิดเวร รปภ. |
| ประวัติเข้า-ออก | ดูประวัติทั้งหมด กรองตามบ้าน/วันที่ |
| ทำเนียบรถรับจ้าง | จัดการรายชื่อวิน/แท็กซี่ที่แนะนำให้ลูกบ้าน |
| จัดการงานซ่อม | ดูใบงาน มอบหมายช่าง เปลี่ยนสถานะ |
| แชท | คุยกับลูกบ้านและ รปภ. + ส่งข้อความกลุ่มหมู่บ้าน |
| **ประวัติตรวจรอบ** | ดูหลักฐานการตรวจรอบของ รปภ. ทุกคน ย้อนหลังได้ พร้อมรูป+เวลา+พิกัด |

## 3. ฟังก์ชันที่ทำงานอยู่เบื้องหลัง (ไม่ต้องกดอะไรเพิ่ม)

- **Push Notification จริง** — แจ้งเตือนเด้งขึ้นแม้ปิดแอป/สลับแอปอยู่ (สแกน QR เข้า, SOS, ประกาศ, ข้อความแชทใหม่)
- **Row-Level Security ระดับฐานข้อมูล** — ป้องกันข้อมูลรั่วข้ามหมู่บ้านตั้งแต่ชั้นดาต้าเบส ไม่ใช่แค่ตรวจในโค้ดแอป
- **แยกเก็บข้อมูลอ่อนไหว** — รูปบัตรประชาชน/ทะเบียนรถ เก็บแยกจากรูปทั่วไป มีนโยบายลบอัตโนมัติหลัง 90 วัน
- **Audit Log** — บันทึกทุกครั้งที่แอดมินเข้าถึงข้อมูลอ่อนไหว (เช่น เปิดดูรูปบัตร ปชช.)

---

## 4. สิ่งที่ยังไม่ได้ทำ (Phase 3 — ยังไม่เริ่ม)

- จองพื้นที่ส่วนกลาง (สระว่ายน้ำ/คลับเฮาส์)
- ชำระค่าส่วนกลางออนไลน์ (ต้องมีบัญชี payment gateway จริงก่อน)
- เชื่อมกล้อง CCTV/อ่านป้ายทะเบียนอัตโนมัติ (LPR) — ต้องมีอุปกรณ์จริง

## 5. ข้อจำกัดทางเทคนิคที่ควรรู้ (สำหรับผู้ดูแลระบบ ไม่ใช่ข้อมูลลูกค้า)

- SMS สำรองสำหรับประกาศฉุกเฉินยังไม่ต่อ (มีแค่ push notification)
- ยังรันบนเครื่อง local เท่านั้น ยังไม่ได้ขึ้น production server จริง
- ยังไม่ผ่านการตรวจสอบความปลอดภัยโดยผู้เชี่ยวชาญภายนอก (penetration test)
